# Front End Developer | LLM

## Verify Influencer Challenge Project

The Verify Influencer Challenge project is a web application designed to analyze and display information about influencers, their claims, and the verification process. The project is hosted on Vercel and can be accessed at [https://verifyinf-tiagogiraldos-projects.vercel.app/leaderboard](https://verifyinf-tiagogiraldos-projects.vercel.app/leaderboard).

Key features of the project include:

### Leaderboard
The application features a comprehensive leaderboard that displays crucial information about influencers:
- Influencer names
- Trust scores
- Follower counts
- Claim statistics

This leaderboard provides a quick overview of the most influential figures and their credibility based on the verification of their claims.

### Influencer Detail Page
Each influencer has a dedicated detail page that offers in-depth information:
- A complete list of claims made by the influencer
- Verification status of each claim
- Confidence scores for the verified claims

This feature allows users to dive deeper into an influencer's track record and assess their reliability.

### Research Configuration
The project includes a research configuration page that enables users to customize their analysis:
- Select specific date ranges for the claims to be analyzed
- Choose the number of claims to include in the analysis
- Select which journals or sources to use for verification

This flexibility allows researchers and users to focus on particular time periods or sources that are most relevant to their interests.

### Data Collection
The data for this project was obtained using a prompt with Perplexity AI's sonar-pro feature, ensuring a comprehensive and up-to-date dataset for analysis.

### Technology Stack
The project is built using Vercel, a cloud platform for static sites and serverless functions, which provides fast and reliable hosting for the web application.

This Verify Influencer Challenge project offers a powerful tool for assessing the credibility of influencers and their claims, providing valuable insights for researchers, marketers, and the general public interested in the accuracy of information shared on social media platforms.
